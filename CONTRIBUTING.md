# Contributing to DocTalk

DocTalk is intended to become a community-maintained resource center.

## Good contributions

- Add a relevant resource
- Correct outdated information
- Report a broken link
- Improve audience or topic metadata
- Add evidence or provenance
- Identify missing populations or geographic coverage
- Improve accessibility

## Resource submissions

Please provide:

- Resource name
- Official source
- Audience
- Topic
- Resource type
- Geographic scope
- Cost/access
- Evidence basis
- Privacy/confidentiality information when relevant
- Date reviewed
- Limitations

## Review

Contributions should be reviewable by maintainers. Prefer primary or official sources and avoid promotional claims.

## Safety

Do not submit private clinical information, patient information, credentials, or other sensitive personal data.

Inclusion does not equal endorsement.
