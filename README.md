# DocTalk

**An open resource center for medical students, residents, physicians, educators, and mental-health professionals.**

DocTalk exists to make medical mental-health resources easier to discover, evaluate, and use.

The problem is not simply a lack of resources. The landscape is fragmented across institutions, professional organizations, nonprofits, physician-health programs, research literature, and peer communities. DocTalk is being built as an open discovery and curation layer.

## Research foundation

- [Medical Mental Health Landscape Report](research/medical-mental-health-landscape-report.md)

## Design principles

**Discoverability.** Help people find what already exists.

**Provenance.** Every resource should have a source and review date.

**Evidence transparency.** Distinguish research evidence from expert guidance, institutional resources, and community resources.

**Audience awareness.** A resource should say who it is actually for.

**Privacy.** The resource center should not require sensitive personal information.

**Safety.** DocTalk is a resource navigator, not a diagnostic or treatment service.

**Open contribution.** Students, residents, physicians, counselors, psychologists, educators, and researchers should be able to improve the collection through reviewable contributions.

## Current build

This repository is in the foundation phase. The immediate target is an initial collection of approximately 50 high-impact resources, represented with structured metadata so the same knowledge base can power a future searchable website and intelligent navigator.
