# DocTalk Curation Standards

## Preferred source hierarchy

1. Official organizational source
2. Government source
3. Peer-reviewed research
4. Professional society
5. Established nonprofit
6. Transparent community resource

## Every resource should answer

- Who is it for?
- What problem does it address?
- What does it actually provide?
- What does it cost?
- Where is it available?
- Is it confidential?
- Is it an emergency resource?
- What evidence supports it?
- Who operates it?
- When was it last reviewed?

## Evidence labels

Use clear language rather than implying false precision:

- Research-supported
- Evidence-informed
- Professional/expert guidance
- Institutional resource
- Peer/community resource
- Informational

## Inclusion rule

Inclusion means the resource was judged relevant enough to catalog. It does not mean DocTalk endorses the resource, guarantees its quality, or substitutes it for professional judgment.

## Maintenance

Every resource should have a review date. Broken, outdated, unsafe, or materially changed resources should be flagged for review.
