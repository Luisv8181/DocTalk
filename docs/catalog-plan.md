# DocTalk Resource Catalog Plan

## Target
Build the first 50 high-value entries across the full DocTalk landscape without sacrificing verification quality.

## Coverage targets
- Crisis & immediate support: 5
- Peer support: 5
- Counseling / EAP / treatment navigation: 5
- Physician Health Programs: 5
- Burnout / stress / professional fulfillment: 5
- Depression / anxiety / suicide prevention: 5
- Trauma / grief / difficult clinical experiences: 4
- Education / curricula: 4
- Assessment / research: 4
- Equity / culture / mentorship / belonging: 4
- AI / technology / privacy: 4

The counts are targets, not quotas. A category may have fewer entries when credible, accessible resources are limited.

## Verification states
- `candidate`: discovered but not yet checked
- `verified-source`: official source and basic identity checked
- `verified-entry`: all published metadata checked against current authoritative source
- `needs-review`: known to have changed or require re-check
- `archived`: no longer suitable for active discovery

Only `verified-entry` resources should be presented as fully published in the future web interface.

## Resource selection rule
Prefer resources that solve a real discovery problem and add something meaningfully different. Do not add five resources that perform the same function merely to inflate the count.
